## 中版（开发者群 / V2EX 预告）

**Chatilus** 是一个桌面端工具，帮你把散落在各平台的 AI 对话导入本地，统一浏览和搜索。

**现在能做什么：**

- 导入 ChatGPT 官方导出（ZIP 或解压目录）
- 全文搜索，点击结果定位到原消息
- 图片图库：按时间浏览、放大、跳回对话
- Timeline：按月回顾跨来源对话
- 收藏、标签、导出 Markdown

**隐私：** 默认不上传数据，不调用外部 LLM，不收集 telemetry。所有内容存在本机 SQLite。

**状态：** 0.2.x 早期内测，Windows 安装包见 Releases。Cursor / Gemini 为 Beta，其他来源实验性。

欢迎试用并到 Issues 反馈（请勿粘贴完整聊天内容）。

GitHub：https://github.com/manxisuo/ChatLens
