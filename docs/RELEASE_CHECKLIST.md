# ChatLens 对外发布任务清单

> 基于当前产品状态（功能接近 0.2.x，发布基建约 0.1.x）整理。  
> 勾选方式：将 `- [ ]` 改为 `- [x]`。

**发布节奏参考**

| 阶段 | 目标 | 完成后可做什么 |
|------|------|----------------|
| **里程碑 A** | 朋友/开发者内测（0.2.x） | 小范围招募 10–30 人试用 |
| **里程碑 B** | 公开 Beta（0.3.x） | V2EX、即刻、知乎等技术社区发 Beta |
| **里程碑 C** | 正式宣传（1.0 方向） | Product Hunt、大力推广、明确主卖点 |

**第一波宣传定位（建议）**

> ChatLens：本地优先的 AI 对话历史浏览器。导入 ChatGPT 历史记录，在本地统一搜索、浏览图片、回顾时间线。Cursor / Gemini 实验性支持。

---

## 里程碑 A：可招募内测（优先完成）

预计工程量：约 1–2 周。完成后即可说「早期内测，欢迎试用」。

### 分发与版本

- [ ] 打 Windows 安装包（`npm run tauri build`）并在本机实测安装/卸载
- [ ] 创建 GitHub Release，附安装包与 SHA256 校验（可选）
- [x] 版本号与 `package.json` / `tauri.conf.json` 对齐（建议升至 `0.2.0`）
- [x] 新增 `CHANGELOG.md`，记录本版主要变更
- [x] 新增 `KNOWN_ISSUES.md`，列出已知限制与规避方式
- [x] README 增加「下载与安装」段落（非仅开发说明）

### 隐私与数据信任

- [x] README 增加「隐私与数据」章节：本地存储、不上传、数据库路径、如何删除
- [x] 应用内增加「隐私与数据」页面（设置菜单或关于页，静态文字即可）
- [x] 明确写清：当前版本不调用外部 LLM、不收集 telemetry
- [x] 说明导入文件是否复制、图片附件缓存策略

### 导入体验

- [x] 导入完成后用对话框替代/增强 Toast，展示结构化报告：
  - [x] 来源名称
  - [x] 新增 / 更新 / 去重对话数
  - [x] 写入消息数、索引媒体数
  - [ ] 失败项数量（若有）
- [x] 报告提供「开始搜索」「打开 Timeline」等下一步按钮
- [x] 导入失败时不崩溃，错误信息人类可读（可复制）
- [ ] 用自己真实 ChatGPT 导出连续测 3 次以上（含重复导入）

### 来源成熟度标签

- [x] ChatGPT 标为 **Stable**（宣传主入口）
- [x] Cursor 标为 **Beta**
- [x] Gemini 标为 **Beta**
- [x] Codex / Copilot / Grok / DeepSeek 等标为 **Experimental** 或 **Planned**
- [x] 导入向导 UI 与上述标签一致，避免过度承诺

### 主路径稳定性自测

- [ ] 会话列表按时间排序正常
- [ ] 打开对话：Markdown、代码块、图片预览正常
- [ ] 全文搜索可用，点击结果能定位到消息
- [ ] 图库可浏览、放大、跳回原对话
- [ ] Timeline 可按月浏览、钻取到对话
- [ ] 收藏对话 / 收藏消息 / 标签基本可用
- [ ] 导出 Markdown 可用
- [ ] 大数据量下（自己的真实库）列表与搜索无明显卡死

### 反馈与社区

- [x] 应用内或 README 提供反馈入口（GitHub Issues 链接等）
- [x] Issue 模板：环境、版本、数据源、复现步骤（不含聊天正文）
- [x] 准备内测招募文案（朋友圈 / 开发者群 / README 置顶）

## 里程碑 B：可公开 Beta 宣传

在里程碑 A 完成后推进。预计再 2–4 周。

### 上手与演示

- [ ] 提供「打开示例 Library」Demo 模式（内置小型示例数据库）
- [ ] 新用户无需导入即可浏览 UI 与核心功能
- [ ] 编写 5 分钟上手指南（导入 → 搜索 → 图库 → Timeline）
- [ ] 准备 3–5 张产品截图
- [ ] 准备 30 秒 GIF 或短视频（搜索命中 / 图库 / Timeline 任选）

### 错误诊断

- [ ] 导入失败时可「复制错误信息」
- [ ] 可「导出诊断报告」（含：版本、OS、数据源类型、错误类型；**不含**聊天正文）
- [ ] 崩溃或严重错误有基本提示，不白屏静默失败

### 陌生用户验证

- [ ] 至少 3 位未参与开发的用户，无协助完成：下载 → 安装 → 导入 ChatGPT → 搜到一条旧对话
- [ ] 记录并修复他们卡住的步骤
- [ ] 汇总内测反馈，更新 `KNOWN_ISSUES.md`

### 文档与页面

- [ ] GitHub Release 页信息完整：系统要求、安装步骤、已知问题链接
- [ ] 各数据源导入说明（至少 ChatGPT 图文步骤）
- [ ] 明确平台支持范围：Windows 首发；macOS / Linux 计划（若暂未支持）

### 宣传素材

- [ ] 确定主卖点：**本地 AI 历史搜索**（辅卖点：AI 图片图库）
- [ ] 起草公开 Beta 帖（V2EX / 即刻 / 知乎 / 推特 择一先发）
- [ ] 帖内不承诺「全平台个人知识库」「自动总结」等未实现能力

## 里程碑 C：可大力宣传（长期）

不要求在内测阶段完成，作为 1.0 方向。

### 产品成熟度

- [ ] 数据库 schema 迁移机制稳定，升级不丢用户数据
- [ ] 多 Library 管理稳定（若已规划）
- [ ] 至少 2–3 个数据源达到 Stable 级别
- [ ] 几千会话、几十万消息规模下性能可接受（有实测数据）
- [ ] UI 达到桌面应用质感（非临时 demo 感）

### 差异化与传播

- [ ] 主卖点可一句话讲清，且有可演示的「哇时刻」
- [ ] 图库案例：「找回以前生成的图」有真实用户故事
- [ ] 搜索案例：「比回 ChatGPT 网页找历史更快」有可复现对比
- [ ] Workspace / 多源项目视图等有里程碑可写进 Roadmap

### 运营与维护

- [ ] 明确的版本升级策略与 Release 节奏
- [ ] 用户数据备份 / 恢复说明
- [ ] 开源协议、商业化或捐赠策略写清楚
- [ ] Product Hunt / 少数派等正式投放素材包

## 发布前红线（未完成则不要公开宣传）

以下任一项未解决，不建议大范围推广：

- [ ] 导入失败会导致整个应用崩溃
- [ ] 重复导入产生不可控大量重复数据
- [ ] 用户无法知晓数据存在哪里、无法删除
- [ ] 搜索结果无法跳回原消息
- [ ] 打开大对话明显卡死
- [x] 没有任何隐私说明
- [x] 没有反馈入口
- [ ] 开发者本人尚未用真实历史数据连续使用数天
